# Brett v. Buffalo Transit Co.

## Majority

Judgment and order affirmed, with costs. All concur, except Dowling, J'., not voting. (The judgment is for defendant for no cause in a bus line negligence action. The order denies plaintiffs’ motion for a new trial.) Present — Taylor, P. J.,- Dowling, Harris, MeCurn and Love, JJ.
