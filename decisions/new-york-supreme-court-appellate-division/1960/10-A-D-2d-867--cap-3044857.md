# Syosset Liquor Store, Inc. v. State Liquor Authority

## Majority

In a proceeding to review a determination of the State Liquor Authority which granted an application for permission to remove a retail liquor package store from one location to another, the apjieal is from so much of an order as dismissed the petition and confirmed the determination. Order insofar as appealed from unanimously affirmed, with costs. No opinion. Present — Nolan, P. J., Beldock, Ughetta, Christ and Pette, JJ.
