# Lanes-Fourteenth Street Corp. v. Boyland

## Majority

Order appealed from modified so as to fix building value at $1,500,000 for the year 1952-53 and, as so modified, the order is affirmed. On this record the values now fixed are justified. All concur. Settle order. Present — Peck, P. J., Cohn, Breitel and Bastow, JJ.
