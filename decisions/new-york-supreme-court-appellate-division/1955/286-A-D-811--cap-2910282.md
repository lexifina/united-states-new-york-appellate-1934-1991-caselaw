# People ex rel. F. W. Woolworth Co. v. Boyland

## Majority

Order unanimously modified so as to fix the land values as follows;
1946-1947 $535,000 (assessed value of land reinstated)
1947-1948 535,000 a
1948-1949 535,000 U
1949-1950 550,000 a
1950-1951 575,000
1951-1952 600,000.
As so modified the order is affirmed. On this record the values now fixed are justified. Settle order on notice. Concur — Cohn, J. P., Callahan, Breitel, Botein and Rabin, JJ.
