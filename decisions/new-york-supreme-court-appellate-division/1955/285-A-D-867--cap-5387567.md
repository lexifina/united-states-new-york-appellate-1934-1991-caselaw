# New York Lerner Co. v. Boyland

## Majority

Order appealed from modified so as to fix value of land at the sum of $300,000 and, as so modified, the order is affirmed. On this record the values now fixed are justified. All concur. Settle order. Present — Peek, P. J., Cohn, Breitel and Bastow, JJ.
