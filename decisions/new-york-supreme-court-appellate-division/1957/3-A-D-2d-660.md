# In re the Arbitration between French Textiles Co. & Senor

## Majority

Order unanimously modified so as to grant the motion to vacate the award and, as so modified, affirmed. While the purpose for remitting the matter to the arbitrators was correct, the order should have provided in the first instance for a vacatur of the award. Settle order on notice. Concur — Peek, P. J., Botein, Rabin and Frank, JJ.
